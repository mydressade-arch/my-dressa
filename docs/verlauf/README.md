# Entwicklungsverlauf

Dieser Ordner enthält die Notizen zu einzelnen Bugfixes und Features,
die während der Entwicklung entstanden sind. Sie dokumentieren, WARUM
bestimmte Änderungen gemacht wurden.

Für den Einstieg ins Projekt siehe stattdessen:
- ../../README.md         → Projektübersicht
- ../../START.md          → Schnellstart
- ../../HOW_TO_TEST.md    → Testen
- ../DATABASE.md          → Datenbankstruktur

## Inhalt hier
- FEATURE_*.md   → einzelne Features (Mietdauer, Verlängerung, Kaution …)
- FIX_*.md       → einzelne Bugfixes mit Ursache und Lösung
- AENDERUNGEN*.md → Änderungsprotokolle
- AUDIT_BERICHT.md → Code-Audit
- BRANDING.md, DESIGN_NEU.md, RESPONSIVE_AUDIT.md → Web-Design-Notizen
- RAILWAY_PORT_FIX.md → Deployment-Notiz

Diese Dateien sind Referenz — man muss sie nicht lesen, um das Projekt
zu betreiben.
